## 原生IP、住宅IP、双ISP，三个词说的不是一回事

先把定义摆清楚，后面看套餐才不会被产品名绕晕。

**原生 IP（Native IP）** 指 IP 的注册地和机房物理位置一致。洛杉矶机房开出来的机器，WHOIS 里国家一栏也是美国，这就叫原生。反过来，机房在美国但 IP 注册在别的国家，就是非原生。

**住宅 IP（Residential IP）** 指这个 IP 被分配给家庭宽带用户使用，归属的 ASN 是 Comcast、AT&T、中华电信这类民用宽带运营商，而不是 Linode、Vultr 这种 IDC 运营商。用 ipinfo.io 这类工具查，type 字段标的是 “ISP” 或 “Residential”，不是 “Hosting” 或 “Data Center”。家宽 IP、住宅 IP 在日常说法里基本是同义词。

**双 ISP** 指同一个 IP 在两个不同民用 ISP 名下都有注册记录，常见的组合是美国 Comcast 加 Charter、香港 iCable 加 HGC。它的作用很实际：某个 ISP 的 IP 段被平台批量标记了，另一个段还能用，相当于多留一条退路。

三者可以叠加。一台机器可以同时是原生 IP、住宅 IP、双 ISP，丽萨主机主推的就是这种三合一的产品。

为什么要为这层属性多付钱？因为平台风控查的就是这个。数据中心 IP 在数据库里带着明确的机房标签，风控系统判定它“不是真人流量”，后面的事就顺理成章了。家宽 IP 没有这个标签，可信度天然高一档。代价也摆在那里：同配置下比 IDC VPS 贵不少，带宽通常还更小，家宽线路上不了机房那种 Gbps 级别。

所以判断标准很清楚：建站、跑爬虫、做科学上网中转，普通 IDC VPS 完全够用，没必要为家宽 IP 多花钱。做账号运营、跨境电商、解锁地区流媒体，家宽 IP 才是刚需。你属于后一种，再往下看套餐；属于前一种，关掉这个页面去挑台年付二三十美元的机器更划算。

## 下单前要确认的几件事

### 1G 内存能装 Windows 吗？

不能。1G 内存的档位只够跑 Linux，要装 Windows 从 2G 内存的配置起步，也就是各产品线的进阶版及以上。

### 双 ISP 是不是给两个 IP？

不是。双 ISP 说的是同一个 IP 在两个民用 ISP 名下都有注册记录，不是分配两个不同的 IP。所有套餐默认 1 个 IPv4，需要多个 IP 单独加购。

### 为什么机器 ping 不通？

部分 IP 段应 IP 提供方要求禁了 ping，收到机器测不了 ping 属于正常情况，不影响实际使用。判断连通性改用其他方式测。

### 退款怎么算？

普通套餐 48 小时内不满意无条件退款。标注“特殊产品，仅退网站余额”的几类 VDS 只退网站余额，不退原支付方式。特价年付版过了退款期不能退。

### 纽约、西雅图要不要自备中转？

要。这两个系列不是大陆直连优化，建议搭配香港或日本的中转节点使用，直连体验会明显打折。
